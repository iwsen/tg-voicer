# TG-Voicer 🎙️➡️📝

Автоматический скрипт для Telegram, который использует **Telegram Premium** для нативного распознавания голосовых сообщений и видеосообщений (кружочков) через MTProto API.

Расшифровка происходит непосредственно серверами Telegram: текст появляется под сообщением в облаке Telegram и виден во всех официальных приложениях (iOS, Android, macOS, Windows, Web), точно так же, как если бы вы сами нажали кнопку **`->A`** в интерфейсе.

---

## ✨ Возможности

- ⚡ **Перехват на лету (Realtime):** Отслеживает все новые входящие голосовые и кружочки и мгновенно отправляет запрос на расшифровку без задержек.
- 🔄 **Фоновая обработка архива (Backfill):** Когда новых сообщений нет («пока скрипт пустой»), он планомерно сканирует историю ваших чатов и прожимает расшифровку для всех существующих голосовых сообщений.
- ☁️ **Мгновенное получение уже расшифрованного текста:** Если голосовое сообщение **уже расшифровывалось ранее** (вами в приложении или кем-то в чате), Telegram возвращает готовый текст из облачного кеша моментально (за миллисекунды, без ожидания нейросети), и скрипт с минимальной задержкой (`cached_delay_seconds = 0.5`) переходит дальше.
- 📝 **Пропуск сообщений с существующим текстом:** Если у голосового сообщения уже есть текстовая подпись (caption), скрипт сразу сохраняет её (`skip_if_already_has_text = true`) и не отправляет лишний запрос в Telegram.
- 💾 **Умное запоминание прогресса:** База данных SQLite (`data/voicer.db`) сохраняет чекпоинты и ID обработанных сообщений. При перезапуске скрипт продолжает ровно с того места, где остановился, не делая повторных запросов.
- 🛡️ **Защита от лимитов (FloodWait):** Настраиваемая пауза между архивными запросами и автоматическая пауза с обратным отсчетом при срабатывании `FloodWaitError`.
- 🎛️ **Гибкая система фильтрации:**
  - Игнорирование по **типам чатов**: каналы (`channels`), группы (`groups`), личные диалоги (`private`), боты (`bots`).
  - Игнорирование **конкретных чатов, каналов или групп** (по числовому ID, `@username` или названию/фразе).
  - Игнорирование **конкретных людей** (по ID, `@username` или имени пользователя).
  - Поддержка белых списков (`allowed_chats`, `allowed_users`), если нужно обрабатывать только избранные чаты/контакты.
  - Поддержка как аудио-голосовых (`.ogg/.opus`), так и круглых видеосообщений (кружочков).

## 🚀 Быстрый старт

### 1. Требования
- Python 3.10+ (рекомендуется Python 3.11+)
- Аккаунт Telegram с активной подпиской **Telegram Premium**

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Получение API Credentials
Для подключения клиенту нужны `api_id` и `api_hash`:
1. Перейдите на официальный сайт [my.telegram.org](https://my.telegram.org).
2. Авторизуйтесь со своего номера телефона.
3. Откройте раздел **API development tools**.
4. Создайте приложение (название любое, например `tg-voicer`) и скопируйте `api_id` (число) и `api_hash` (строка).

### 4. Первый запуск
Запустите скрипт:
```bash
python3 main.py
```
- Если файла `config.toml` ещё нет, программа сама создаст его и вежливо запросит ваш `api_id` и `api_hash` прямо в консоли, после чего сохранит их.
- Затем Telethon запросит ваш номер телефона, код подтверждения из Telegram и пароль двухфакторной аутентификации (2FA, если он установлен).
- Сессия сохранится в файл `data/tg_voicer.session`. При следующих запусках пароли и коды вводить больше не потребуется!

## ⚙️ Конфигурация (`config.toml`)

Все настройки задаются в файле `config.toml`. Пример файла с комментариями:

```toml
[telegram]
api_id = 12345678
api_hash = "abcdef0123456789abcdef0123456789"
session_name = "tg_voicer"

# Расшифровывать обычные голосовые
transcribe_voice = true

# Расшифровывать кружочки
transcribe_video_notes = true

# Расшифровывать свои собственные отправленные голосовые (false - только входящие)
transcribe_outgoing = false


[filters]
# 1. Типы чатов, которые нужно ИГНОРИРОВАТЬ:
# "channels" (каналы), "groups" (группы и супергруппы), "private" (личка), "bots" (боты)
ignore_types = ["channels"]

# 2. Конкретные чаты/каналы/группы для игнорирования (по ID, @username или названию):
ignored_chats = [
    "@spam_channel",
    -1001234567890,
    "Рабочий флуд"
]

# 3. Конкретные пользователи, чьи голосовые нужно игнорировать:
ignored_users = [
    "@annoying_user",
    123456789,
    "Иван Иванов"
]

# 4. Белый список чатов (если не пустой, обрабатываются ТОЛЬКО указанные):
allowed_chats = []

# 5. Белый список пользователей (если не пустой, расшифровываются ТОЛЬКО эти люди):
allowed_users = []


[realtime]
# Отслеживание новых входящих голосовых в реальном времени
enabled = true
# Ожидать завершения распознавания, если Telegram взял сообщение в обработку
wait_for_completion = true
timeout_seconds = 30


[backfill]
# Обработка архивных сообщений в фоне
enabled = true
# Пауза между запросами к архивным голосовым (во избежание FloodWait)
delay_seconds = 2.0
# Лимит сообщений на один чат (0 = без ограничений, вся история)
max_messages_per_chat = 0
# Размер пачки при чтении истории
batch_size = 100


[storage]
db_path = "data/voicer.db"


[logging]
level = "INFO"
log_to_file = true
log_file_path = "data/voicer.log"
```

## 🎯 Примеры сценариев настройки

### Сценарий 1: Расшифровывать только личные сообщения (игнорировать все группы и каналы)
```toml
[filters]
ignore_types = ["channels", "groups"]
```

### Сценарий 2: Расшифровывать всё, кроме определённого рабочего чата и одного пользователя
```toml
[filters]
ignored_chats = ["Рабочая курилка", "@noisy_channel"]
ignored_users = ["@colleague_username", "Спамер"]
```

### Сценарий 3: Расшифровывать голосовые только в одном конкретном важном чате
```toml
[filters]
allowed_chats = ["@important_project_group"]
```

## 🛠️ Флаги и команды CLI

| Команда / Флаг | Описание |
|---|---|
| `python3 main.py` | Стандартный запуск: мгновенный Realtime-перехват + фоновый Backfill архива |
| `python3 main.py --live-only` | Работать **только** на отлов новых голосовых (без сканирования старой истории) |
| `python3 main.py --backfill-only` | **Только** обработать существующий архив и завершить работу |
| `python3 main.py --stats` | Показать красивую сводную статистику и последние расшифровки из базы данных |
| `python3 main.py --reset-backfill` | Сбросить прогресс сканирования истории для повторного обхода всех чатов |
| `python3 main.py --dry-run` | Тестовый прогон: поиск сообщений и проверка фильтров **без** реального вызова API |
| `python3 main.py -v` (`--verbose`) | Включить подробный отладочный вывод (DEBUG) |
| `python3 main.py -c /path/config.toml` | Использовать кастомный путь к файлу конфигурации |

## 🖥️ Запуск 24/7 в фоновом режиме

### Вариант 1: Через tmux или screen
```bash
tmux new -s tg-voicer
python3 main.py
# Нажмите Ctrl+B, затем D, чтобы отсоединиться от сессии tmux
```

### Вариант 2: macOS LaunchAgent (автозапуск при входе в систему)
Создайте файл `~/Library/LaunchAgents/com.user.tgvoicer.plist`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.user.tgvoicer</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/bin/python3</string>
        <string>/Users/donbass/Documents/github/tg-voicer/main.py</string>
    </array>
    <key>WorkingDirectory</key>
    <string>/Users/donbass/Documents/github/tg-voicer</string>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
</dict>
</plist>
```
Активируйте службу:
```bash
launchctl load ~/Library/LaunchAgents/com.user.tgvoicer.plist
```

## 🔒 Безопасность

- Все ваши сессионные файлы (`data/*.session`) и локальная база данных (`data/voicer.db`) хранятся исключительно локально на вашем компьютере и внесены в `.gitignore`.
- Ваши голосовые сообщения не передаются никаким сторонним серверам (OpenAI, Whisper и т.д.) — распознавание выполняет сам Telegram в рамках вашей подписки Telegram Premium.
